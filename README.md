# Silang Alert locator (Vercel)
1. Push this folder to GitHub, then import it in Vercel (framework preset: Other).
2. In the Vercel project: Storage > Marketplace > Upstash Redis (free) > connect to the project.
3. Settings > Environment Variables: add STAFF_PASSWORD (your own password).
4. Redeploy. Open the site, sign in, create a link, send it to the caller.
Edit the PUROKS list near the top of the script in share.html.
